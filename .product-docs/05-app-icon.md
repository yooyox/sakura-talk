# App 图标设计

## 设计理念

- **风格**：简笔画、手绘风格
- **色彩**：黑白为主
- **调性**：可爱、温暖、友好（参考动物森友会）
- **辨识度**：简洁独特，易于识别

---

## 最终方案（用户手绘）

### 设计要求

| 项目 | 要求 |
|------|------|
| 主题 | 小熊 或 小狗 |
| 风格 | 黑白简笔画，可爱风格 |
| 尺寸 | 最终需要 1024×1024 像素 |

### 需要绘制的版本

| 版本 | 内容 | 状态 |
|------|------|------|
| A1 | 小熊 + 对话气泡 | 待绘制 |
| A2 | 纯小熊头像 | 待绘制 |
| B1 | 小狗 + 对话气泡 | 待绘制 |
| B2 | 纯小狗头像 | 待绘制 |

### 手绘建议

1. **纸张选择**：白纸，用黑色笔绘制
2. **线条要求**：粗细一致，清晰简洁
3. **表情设计**：温暖、友好、微笑
4. **避免**：过多细节、阴影、复杂线条

### 手绘后步骤

1. 拍照或扫描手绘稿
2. 可用 Procreate/Figma 转成数字版本
3. 提供给我，我帮你评估哪个更适合
4. 确定后进行矢量化处理

- **日期**：2026-07-21
- **决策**：由用户手绘 4 个版本（小熊/小狗 × 有气泡/无气泡）
- **后续**：手绘完成后评估选择

---

## 启动页设计

### 决策：不需要启动页

**原因**：
- 参考 iOS 原生应用，无启动页更流畅
- 用户更快进入功能
- 整体体验更简洁

---

## 首次使用引导

### 决策：不需要引导页

**原因**：
- 功能简单，用户可快速上手
- 有引导会显得啰嗦
- 保持简洁的产品体验
