# UI 设计规范

> 打造简洁、清爽、好用、美观的旅游翻译 App

---

## 一、设计理念

### 核心关键词

**简洁** - 去除冗余，只保留必要元素
**清爽** - 宽松留白，呼吸感强
**好用** - 操作直观，反馈及时
**美观** - 细节精致，视觉舒适

### 设计参考

- **Notion**：黑白简洁，专业耐看
- **Apple 原生应用**：自然流畅，原生体验
- **小红书**：清新界面，年轻友好

---

## 二、整体风格

### 2.1 视觉密度

| 属性 | 规范 |
|------|------|
| 密度 | **宽松透气** |
| 留白 | 充足，呼吸感强 |
| 信息层次 | 清晰，不拥挤 |
| 参考 | Apple Music、Calm |

### 2.2 圆角规范

| 元素 | 圆角值 |
|------|--------|
| 按钮 | 16px |
| 卡片 | 16px |
| 输入框 | 16px |
| 气泡 | 16-20px |
| 弹窗 | 20px |
| 小标签 | 12px |

### 2.3 动效风格

| 类型 | 规范 |
|------|------|
| 整体风格 | **自然流畅**，跟随 iOS 系统风格 |
| 过渡动画 | 使用系统标准时长 (0.25-0.35s) |
| 交互反馈 | 适度，不喧宾夺主 |
| 弹性效果 | 轻微，不夸张 |

## 三、颜色系统

### 3.1 基础色（黑白为主）

| 名称 | 色值 | 用途 |
|------|------|------|
| 纯白 | #FFFFFF | 背景、卡片 |

## 六、按钮系统

### 6.1 按钮类型

| 类型 | 样式 | 用途 |
|------|------|------|
| **主要按钮** | 填充背景（雾霾蓝绿） | 翻译、保存等主要操作 |
| **次要按钮** | 线框（雾霾蓝绿边框） | 取消、重新拍照等次要操作 |
| **文字按钮** | 纯文字，无背景 | 辅助操作，如"跳过" |

### 6.2 按钮尺寸

| 尺寸 | 高度 | 内边距 | 字号 |
|------|------|--------|------|
| 大按钮 | 50pt | 24px 水平 | 16pt |
| 中按钮 | 44pt | 20px 水平 | 16pt |
| 小按钮 | 36pt | 16px 水平 | 14pt |

### 6.3 按钮状态

| 状态 | 样式 |
|------|------|
| 正常 | 填充主色/线框 |
| 点击 | 背景/边框加深 10% |
| 禁用 | 透明度 50% |
| 加载中 | 显示系统加载圈 |

## 十四、设计检查清单

在开发每个页面时，检查以下要素：

### ✅ 布局
- [ ] 留白充足，不拥挤
- [ ] 元素对齐一致
- [ ] 层次清晰

### ✅ 颜色
- [ ] 主色调为黑白
- [ ] 强调色仅在必要处使用
- [ ] 文字对比度足够

### ✅ 字体
- [ ] 使用 SF Pro 字体
- [ ] 字号符合规范
- [ ] 行高适当

### ✅ 圆角
- [ ] 按钮圆角 16px
- [ ] 卡片圆角 16px
- [ ] 气泡圆角 16-20px

### ✅ 交互
- [ ] 点击区域足够大 (≥44pt)
- [ ] 有明确的视觉反馈
- [ ] 加载状态清晰

### ✅ 空状态
- [ ] 有插画和文案
- [ ] 有引导操作

```swift
extension Color {
    // 基础色
    static let pureBlack = Color(hex: "#000000")
    static let pureWhite = Color(hex: "#FFFFFF")
    static let textPrimary = Color(hex: "#333333")
    static let textSecondary = Color(hex: "#666666")
    static let textTertiary = Color(hex: "#999999")
    static let divider = Color(hex: "#E5E5E5")
    static let backgroundGray = Color(hex: "#F5F5F5")

    // 强调色
    static let hazeBlueGreen = Color(hex: "#7D9B9D")
    static let bubbleGray = Color(hex: "#F2F2F2")

    // 功能色
    static let success = Color(hex: "#34C759")
    static let warning = Color(hex: "#FF9500")
    static let error = Color(hex: "#FF3B30")
}
```
