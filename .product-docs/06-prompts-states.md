# 提示语与状态设计

## 设计理念

- **风格**：可爱、温暖、友好
- **参考**：B站的小设计、动物森友会
- **调性**：简洁但不冷漠，可爱但不啰嗦

---

## 一、权限请求

### 决策：直接请求系统权限

- 不需要额外的说明弹窗
- 直接弹出系统权限框
- 简洁、快速

### 权限说明文案

| 权限 | 系统弹窗说明文案 |
|------|------------------|
| 麦克风 | 「Sakura Talk 需要使用麦克风来进行语音翻译」 |
| 相机 | 「Sakura Talk 需要使用相机来拍照翻译」 |
| 相册 | 「Sakura Talk 需要访问相册来选择照片翻译」 |

---

## 二、权限拒绝提示

### 决策：提示但允许继续

当用户拒绝权限时：
- 显示友好提示
- 不强制跳转设置
- 允许使用其他功能

### 提示文案

| 场景 | 提示语 |
|------|--------|
| 麦克风权限未开启 | 「哎呀，没有麦克风我听不到你说话呢～如需使用语音翻译，可以去设置开启哦」 |
| 相机权限未开启 | 「唔...相机被关掉了～如果需要拍照翻译，可以去设置开启哦」 |
| 相册权限未开启 | 「相册打不开啦～如果需要选择照片，可以去设置开启哦」 |

---

## 三、错误提示

### 网络相关

| 场景 | 提示语 |
|------|--------|
| 无网络 | 「咦？网络好像断掉了，检查一下吧～」 |
| 网络不稳定 | 「网络有点慢哦，再试一次？」 |
| 请求超时 | 「等了好久都没反应...再试一次吧」 |

### 翻译相关

| 场景 | 提示语 |
|------|--------|
| 语音识别失败 | 「嗯？刚刚没听清，可以说得清楚一点吗？」 |
| 翻译失败 | 「糟糕，翻译出了点问题，再试一次？」 |
| 无法识别语言 | 「好像不是中文或日语呢，换个说法试试？」 |

### 相机/图片相关

| 场景 | 提示语 |
|------|--------|
| 相机打开失败 | 「相机好像罢工了...稍后再试？」 |
| 图片识别失败 | 「这个有点难认呢...拍清楚一点试试？」 |
| 未检测到文字 | 「没找到文字呢，换个角度试试？」 |

## 四、空状态提示

### 历史记录为空

```
┌─────────────────────────────────────┐
│                                     │
│           📭                        │
│                                     │
│       还没有记录哦～                │
│     去翻译点什么吧！                │
│                                     │
│      [ 开始翻译 ]                   │
│                                     │
└─────────────────────────────────────┘
```

**提示语**：「还没有记录哦～去翻译点什么吧！」

---

## 五、加载状态

### 翻译中

| 场景 | 提示语 |
|------|--------|
| 正在翻译 | 「正在翻译中...」 |
| 正在识别 | 「正在听...」 |
| 正在处理图片 | 「正在识别图片...」 |

### 可选：加载动画

- 可以使用简单的黑白动画
- 或者手绘风格的简笔画动画
- 与整体风格保持一致

## 六、成功提示

### 操作成功

| 场景 | 提示语 |
|------|--------|
| 保存成功 | 「已保存～」 |
| 复制成功 | 「已复制到剪贴板」 |
| 删除成功 | 「删除啦」 |

## 七、确认弹窗

### 删除确认

```
┌─────────────────────────────────────┐
│                                     │
│      确定要删除这条记录吗？         │
│                                     │
│   [ 取消 ]           [ 删除 ]      │
│                                     │
└─────────────────────────────────────┘
```

**文案**：「确定要删除这条记录吗？」

---

## 设计原则总结

| 原则 | 说明 |
|------|------|
| 可爱 | 使用「～」、拟人化表达 |
| 简洁 | 一句话说完，不啰嗦 |
| 友好 | 不责备用户，提供解决方案 |
| 温暖 | 像朋友在说话，不是机器 |
