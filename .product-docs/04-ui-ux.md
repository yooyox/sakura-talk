# UI/UX 设计文档

## 设计原则

- 简洁、易用、快速
- 专注旅游场景
- 操作直观，学习成本低
- **莫兰迪色调**：柔和、高级、不刺眼
- **手绘风格**：可爱、独特、有温度（录音动画等）

---

## 设计风格参考

- 小红书：简洁清新的界面风格
- 喜茶：手绘简笔画风格
- 动物森友会：可爱温暖的视觉感受

## 二、对话模块设计

### 2.1 界面布局

```
┌─────────────────────────────────────┐
│  ←  对话翻译                    ⋯   │
├─────────────────────────────────────┤
│                                     │
│  ┌─────────────────────┐            │
│  │ 🇯🇵 こんにちは      │            │
│  │    你好             │            │
│  └─────────────────────┘            │
│                                     │
│            ┌─────────────────────┐  │
│            │ 谢谢 🇨🇳            │  │
│            │    ありがとう       │  │
│            └─────────────────────┘  │
│                                     │
├─────────────────────────────────────┤
│                                     │
│  [点击左侧输入日语]                 │
│  [点击右侧输入中文]                 │
│                                     │
│    [ 按住说话 ]      [ 键盘输入 ]   │
│                                     │
└─────────────────────────────────────┘
```

### 2.2 交互设计

#### 谁在说话：点击区域切换

| 操作 | 效果 |
|------|------|
| 点击左侧区域 | 切换为日语输入（代表日本人） |
| 点击右侧区域 | 切换为中文输入（代表中国人） |

#### 语音输入：按住说话，松开结束

| 操作 | 效果 |
|------|------|
| 按住按钮 | 开始录音，显示手绘动画 |
| 松开按钮 | 结束录音，开始识别 |
| 识别完成 | 显示原文（可编辑），确认后翻译 |

#### 翻译结果：原文 + 译文并排显示

每个气泡显示：
- 第一行：原文 + 国旗标识
- 第二行：译文

### 2.3 气泡样式

| 元素 | 日语气泡 | 中文气泡 |
|------|----------|----------|
| 对齐 | 左对齐 | 右对齐 |
| 背景色 | 浅灰色 (#F2F2F2) | 雾霾蓝绿 (#7D9B9D) |
| 文字颜色 | 黑色 (#333333) | 白色 (#FFFFFF) |
| 语言标识 | 🇯🇵 日本国旗 | 🇨🇳 中国国旗 |

### 2.4 录音状态

| 状态 | 视觉效果 |
|------|----------|
| 空闲 | 按钮显示"按住说话" |
| 录音中 | 手绘风格帧动画循环播放 + 录音时长 |
| 识别中 | 显示"正在识别..."加载动画 |

> **录音动画**：手绘简笔画风格，主题待用户设计
>
> 设计参考：喜茶、动物森友会

## 三、拍照模块设计

### 3.1 界面布局

```
┌─────────────────────────────────────┐
│  ←  拍照翻译                    ⋯   │
├─────────────────────────────────────┤
│                                     │
│      ┌───────────────────────┐      │
│      │                       │      │
│      │    相机取景框         │      │
│      │                       │      │
│      └───────────────────────┘      │
│                                     │
├─────────────────────────────────────┤
│                                     │
│   📷        🔆        🖼️          │
│  拍照      闪光灯    相册          │
│                                     │
└─────────────────────────────────────┘
```

### 3.2 输入方式

| 方式 | 说明 |
|------|------|
| 现场拍照 | 打开相机拍摄 |
| 相册选择 | 从相册选择已有照片翻译 |

### 3.3 翻译结果展示

**采用图上标注方式**

```
┌─────────────────────────────────────┐
│  ←  翻译结果                    💾  │
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐    │
│  │      原始图片               │    │
│  │                             │    │
│  │   ┌──────────────┐          │    │
│  │   │ 拉面 ¥800   │ ← 标注框 │    │
│  │   └──────────────┘          │    │
│  └─────────────────────────────┘    │
│                                     │
│  [📋 复制]        [🔄 重新拍照]    │
└─────────────────────────────────────┘
```

**标注框设计：**
- 半透明白色背景 (rgba(255,255,255,0.85))
- 黑色文字
- 圆角矩形
- 定位在识别文字附近

### 3.4 功能按钮

| 按钮 | 功能 |
|------|------|
| 💾 保存 | 保存到历史记录 |
| 📋 复制 | 复制翻译文字 |
| 🔄 重新拍照 | 返回相机重新拍摄 |

## 四、历史记录模块设计

### 4.1 整体布局

**采用时间轴设计（简洁黑白风格）**

```
┌─────────────────────────────────────┐
│  ←  历史记录                        │
├─────────────────────────────────────┤
│                                     │
│  ┌─────────────────────────────┐    │
│  │  📅 2026.07.20 - 2026.07.21 │ ▼  │  ← 日期筛选按钮
│  └─────────────────────────────┘    │
│                                     │
│  7月21日                           │  ← 日期靠左，字号大
│                                     │
│  ●─── 📸 拉面菜单翻译              │
│  │     14:30                       │  ← 时间靠左，字号稍小
│  │                                 │
│  ●─── 💬 餐厅点餐对话              │
│  │     12:15                       │
│  │                                 │
│                                     │
│  7月20日                           │
│                                     │
│  ●─── 📸 地铁站牌翻译              │
│  │     09:45                       │
│                                     │
└─────────────────────────────────────┘
```

### 4.2 时间轴设计要点

| 元素 | 设计 |
|------|------|
| 日期分组 | 靠左显示，字号较大 |
| 时间 | 靠左显示，字号比日期小 |
| 时间线 | 左侧垂直线，圆点节点 |
| 卡片 | 简洁卡片，黑白色调 |

### 4.3 日期筛选弹窗

```
┌─────────────────────────────────────┐
│                                     │
│   ┌───────────┐  ┌───────────┐     │
│   │ 2026.07.20│  │ 2026.07.21│     │  ← 两个圆润方框
│   │  开始日期 │  │  结束日期 │     │
│   └───────────┘  └───────────┘     │
│         ↑ 默认选中左边              │
│                                     │
│   ┌─────────────────────────────┐   │
│   │      2026    年              │   │
│   ├─────────────────────────────┤   │
│   │        7     月              │   │  ← 滚轮选择器
│   ├─────────────────────────────┤   │  （上滑下滑调整）
│   │       20     日              │   │
│   └─────────────────────────────┘   │
│                                     │
│      [ 重置 ]        [ 确认 ]      │
│                                     │
└─────────────────────────────────────┘
```

**交互说明：**
- 弹窗默认选中左边方框（开始日期）
- 点击方框切换编辑开始/结束日期
- 滚轮支持上滑下滑调整年、月、日
- "重置"按钮清空筛选，显示全部
- "确认"按钮应用筛选

### 4.4 记录类型区分

| 类型 | 图标 | 标题 |
|------|------|------|
| 拍照翻译 | 📸 | 系统自动生成（基于翻译内容），支持用户自定义 |
| 对话记录 | 💬 | 系统自动生成（首条消息），支持用户自定义 |

### 4.5 卡片标题

- **默认**：系统自动生成
- **支持**：用户自定义标题（保存时可编辑）

### 4.6 删除功能

| 方式 | 说明 |
|------|------|
| 详情页删除 | 详情页底部有删除按钮 |
| 左滑删除 | 列表中左滑卡片显示删除选项 |

### 4.7 颜色方案

| 元素 | 颜色 |
|------|------|
| 时间线 | 浅灰色 (#E5E5E5) |
| 节点 | 深灰色 (#333333) |
| 日期 | 深灰色 (#333333)，字号大 |
| 时间 | 中灰色 (#666666)，字号小 |
| 卡片背景 | 白色 (#FFFFFF) |

## 五、颜色系统

| 卡片背景 | #FFFFFF | #2A2A2A |
| 主文字 | #333333 | #FFFFFF |
| 次要文字 | #666666 | #AAAAAA |
