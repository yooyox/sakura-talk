# 设置页面设计

## 设计理念

- **简洁**：只保留必要的设置项
- **黑白**：与整体风格一致
- **直观**：一目了然，不需要说明

## 二、设置项详情

### 2.1 语言设置

**用途**：设置翻译的源语言和目标语言

```
┌─────────────────────────────────────┐
│  ←  语言设置                        │
├─────────────────────────────────────┤
│                                     │
│  翻译语言                           │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  中文 ⇄ 日语              │ ✓  │  ← 默认选项
│  └─────────────────────────────┘    │
│                                     │
│  说明：当前仅支持中日互译          │
│                                     │
└─────────────────────────────────────┘
```

**MVP 说明**：
- 默认中日互译
- 暂不支持其他语言
- 后续可扩展

---

### 2.2 深色模式

**MVP 状态**：
- 显示在设置中，但标注"敬请期待"
- 或：直接隐藏，后续版本再加

**后续实现**：
- 跟随系统
- 手动开启/关闭

```
┌─────────────────────────────────────┐
│  深色模式                           │
│                                     │
│  ○ 跟随系统                         │
│  ○ 开启                             │
│  ○ 关闭                             │
│                                     │
└─────────────────────────────────────┘
```

---

### 2.3 清除历史记录

**功能**：一键清除所有保存的翻译历史

```
┌─────────────────────────────────────┐
│                                     │
│  确定要清除所有历史记录吗？         │
│  此操作不可恢复。                   │
│                                     │
│   [ 取消 ]           [ 清除 ]      │
│                                     │
└─────────────────────────────────────┘
```

**提示语**：「确定要清除所有历史记录吗？此操作不可恢复。」

### 2.5 隐私政策

**说明**：上架 App Store 必须提供隐私政策链接

**内容要点**：
- 收集的数据：无（本地存储为主）
- 权限使用：麦克风、相机、相册的用途说明
- 第三方服务：如有使用第三方 API，需说明

## 三、设置项清单

### MVP 必须有

| 设置项 | 说明 |
|--------|------|
| 关于我们 | 版本号、联系方式、好评入口 |
| 隐私政策 | App Store 上架必须 |
| 用户协议 | 建议提供 |

### MVP 可选

| 设置项 | 说明 |
|--------|------|
| 语言设置 | 当前仅中日互译，可简化 |
| 清除历史记录 | 提供数据管理入口 |

### 后续版本

| 设置项 | 说明 |
|--------|------|
| 深色模式 | 后续支持 |
| 通知设置 | 不需要 |
| 更多语言 | 后续扩展 |

## 四、设计细节

### 列表样式

| 元素 | 样式 |
|------|------|
| 分割线 | 浅灰色 (#E5E5E5) |
| 文字 | 黑色 (#333333) |
| 箭头 | 灰色 (#999999) |
| 背景 | 白色 (#FFFFFF) |

### 交互

| 操作 | 效果 |
|------|------|
| 点击设置项 | 跳转子页面或弹窗 |
| 点击清除历史记录 | 弹出确认框 |
