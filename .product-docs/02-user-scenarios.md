# 用户场景分析

## 场景分类

我们按照旅游流程来梳理用户场景：

---

## 1. 出行前准备

### 场景 1.1：学习基础用语
- 用户想在出发前学习一些基础日语
- App提供常用短语的预习功能
- 支持收藏、练习

### 场景 1.2：下载离线包
- 用户担心日本网络问题
- 提前下载离线翻译包
- 确保无网络时也能使用

---

## 2. 交通出行

### 场景 2.1：乘坐地铁/电车
- **痛点**：站名看不懂、路线复杂
- **需求**：
  - 翻译站名、路线指示
  - 询问"这趟车去XX吗？"
  - 确认换乘信息

### 场景 2.2：乘坐出租车
- **痛点**：无法告诉司机目的地
- **需求**：
  - 展示地址给司机
  - 翻译司机的话
  - 确认费用

### 场景 2.3：问路
- **痛点**：听不懂路人指路
- **需求**：
  - 实时语音翻译
  - 展示地图位置

---

## 3. 住宿

### 场景 3.1：酒店入住
- **痛点**：入住沟通困难
- **需求**：
  - 翻译入住相关对话
  - 询问WiFi、早餐等设施
  - 表达特殊需求（如高楼层、禁烟）

### 场景 3.2：民宿沟通
- **痛点**：民宿主人可能不会英语
- **需求**：
  - 房屋设施询问
  - 周边推荐询问

---

## 4. 餐饮

### 场景 4.1：看菜单
- **痛点**：日文菜单看不懂
- **需求**：
  - 拍照翻译菜单
  - 了解菜品内容、价格
  - 表达忌口需求（过敏、不吃生食等）

### 场景 4.2：点餐沟通
- **痛点**：无法表达需求
- **需求**：
  - "我要这个"
  - "这个辣吗？"
  - "可以少盐吗？"
  - "多久能上菜？"

### 场景 4.3：结账
- **痛点**：支付方式确认
- **需求**：
  - "可以用支付宝/微信吗？"
  - "可以分开结账吗？"

---

## 5. 购物

### 场景 5.1：询问商品
- **痛点**：无法询问商品信息
- **需求**：
  - "这个有别的颜色吗？"
  - "可以试穿吗？"
  - "这个免税吗？"

### 场景 5.2：比价
- **痛点**：看不懂价格标签
- **需求**：
  - 价格翻译换算
  - 折扣信息翻译

### 场景 5.3：退税
- **痛点**：退税流程不熟悉
- **需求**：
  - 退税相关对话翻译

---

## 6. 景点游玩

### 场景 6.1：看展馆介绍
- **痛点**：展馆说明只有日文
- **需求**：
  - 拍照翻译介绍文字

### 场景 6.2：购票
- **痛点**：购票窗口沟通
- **需求**：
  - 票种询问
  - 优惠询问

---

## 7. 紧急情况

### 场景 7.1：生病就医
- **痛点**：描述病情困难
- **需求**：
  - 症状描述模板
  - 医疗相关词汇翻译

### 场景 7.2：物品遗失
- **痛点**：无法描述丢失情况
- **需求**：
  - 遗失申报模板

### 场景 7.3：报警
- **痛点**：紧急情况无法沟通
- **需求**：
  - 紧急短语快捷翻译
