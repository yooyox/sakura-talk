## 本次会话成果

### 1. TranslationService（翻译服务）

封装 Apple Translation Framework（iOS 26+）：
- `translate(text:from:to:)` - 通用翻译方法
- `translateChineseToJapanese(_:)` - 中译日
- `translateJapaneseToChinese(_:)` - 日译中
- API：`TranslationSession(installedSource:target:)` + `session.translate(text)`

### 2. ConversationViewModel（对话业务逻辑）

- `sendJapanese()` / `sendChinese()` - 左右分别发送
- `deleteMessage(_:)` - 删除单条消息
- `saveConversation()` - 保存到 SwiftData
- `clearConversation()` - 清空当前对话
- 状态：`messages` / `japaneseInputText` / `chineseInputText` / `isLoading`

## 关键设计决策

1. **双人输入模式**：左右各一个输入框，日本人用左边，中国人用右边，不需要手动切换语言
2. **历史移入菜单**：底部 Tab 只保留"对话"和"拍照"，历史通过右上角"..."访问
3. **未保存即消失**：消息只存内存，不点保存关闭 App 后自动清除
4. **气泡内选取**：使用 `.textSelection(.enabled)` 让用户直接在气泡里选文字复制
5. **输入框扩展**：`lineLimit(1...5)` + `HStack(alignment: .bottom)` 实现自动增高

## 踩坑记录（本次新增）

1. **Translation Framework API 变化**：iOS 26 的 `TranslationSession` 使用 `init(installedSource:target:)` 初始化，而非 `Configuration` 模式。iOS 18 的 API 在 iOS 26 中已变更。
2. **pbxproj 手动编辑易出错**：用 Python 脚本添加文件时，正则替换容易破坏 section 结构。建议替换后用 `xcodebuild` 验证。
3. **@Bindable 作用域**：`@Bindable var x = vm` 只能在声明它的函数内使用 `$x`，不能作为参数传递给其他函数。每个需要绑定的函数都要单独声明。
4. **SourceKit 诊断不可靠**：新文件添加后 SourceKit 报大量 "Cannot find type" 错误，但 `xcodebuild` 可以正常编译。以实际编译结果为准。
5. **免费 Apple ID 真机测试流程**：需开启开发者模式（设置→隐私与安全性→开发者模式→重启），然后信任证书（设置→通用→VPN与设备管理）。
6. **ScrollView 内 Spacer 无效**：空状态视图不能用 Spacer 撑高，改用 `.frame(maxHeight: .infinity)` 或固定 minHeight。
