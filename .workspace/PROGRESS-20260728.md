## 本次会话成果

### 1. 数据模型（SwiftData @Model）

| 模型 | 关键字段 | 关系 |
|------|----------|------|
| `Conversation` | title / createdAt / updatedAt / isFavorite | @Relationship(.cascade) → [Message] |
| `Message` | sourceText / translatedText / language / position / createdAt | 属于 Conversation |
| `PhotoTranslation` | imageData / recognizedText / translatedText / note / isFavorite / createdAt | 独立 |

> **关键经验**：`ModelContainer(for:)` 必须注册**所有** @Model 类型，包括 @Relationship 的目标类型。否则示例数据写入后查询返回 0 条（曾踩坑：未注册 `Message.self`，导致数据不显示）。

## 踩坑记录（避免重复）

1. **新 Swift 文件不在 Xcode 项目中**：需手动编辑 `project.pbxproj`，添加 PBXBuildFile / PBXFileReference / PBXGroup / PBXSourcesBuildPhase 条目。注意**不要**把 Info.plist 放进编译源（会报 "Multiple commands produce Info.plist"）。
2. **SwiftData ModelContainer 必须包含所有 @Model 类型**：含 @Relationship 目标类型（如 Message.self）。
3. **左滑操作必须在 List 中**：ScrollView 下自定义 DragGesture 实现不可靠；改用 List + 原生 `swipeActions`。
4. **自定义 Color 扩展**：在 `.tint()` / `.foregroundStyle()` 中需用 `Color.morandiRed` 而非 `.morandiRed`（ShapeStyle 推断问题）。
5. **@Query 优于手动 fetch**：手动 save 后 fetch 有时序问题，@Query 自动刷新更稳。
