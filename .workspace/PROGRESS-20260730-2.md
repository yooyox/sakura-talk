## 本次会话成果

### 1. 长按菜单：系统 contextMenu → 小红书风格悬浮菜单

**问题背景**：
- SwiftUI 的 `.contextMenu` 自带"抬起预览"动画（灰色快照方框），用户觉得不够干净
- 曾尝试 `preview: { EmptyView() }`（变成白点）、`preview: { ChatBubbleView }`（气泡缩小+白色方框），都不理想
- 曾尝试 `.textSelection(.enabled)` + 微信风格光标选取，但 SwiftUI 无法程序化触发光标，UIKit UITextView 方案也没能正常弹光标
- 用户最终决定：**回归小红书风格**——不要选取文字，只要干净的一键操作

**最终实现**：
- 用 `.onLongPressGesture` 替代 `.contextMenu`（完全避开系统预览动画）
- `BubbleFloatingMenu`：黑色半透明胶囊（`Capsule`，85% 不透明度），白色图标+文字，中间竖线分隔
- 通过 `.overlay(alignment: .top)` + `.offset(y: -40)` 悬浮在气泡正上方
- `scale(0.8, anchor: .bottom)` + spring 动画从气泡底部弹出
- "复制"默认拷贝**原语言**（左气泡=日语，右气泡=中文）
- 点击聊天区空白处关闭菜单（`onTapGesture` 里 `activeMenuMessage = nil`）

**踩坑**：胶囊菜单里的 `Text("复制")` 被压缩成"..."，需加 `.fixedSize()` 防止截断。

### 2. 气泡重设计：左白右灰 + 不对称圆角

**配色决策**：
- 用户否决了原来的雾霾蓝绿（`hazeBlueGreen`）中文气泡，希望保持黑白极简
- 讨论过左白右黑（强对比）、双白、左灰右黑三个方案
- 用户最终选择 **左白右灰**——比纯黑安静，符合日系极简气质，延续微信"自己=带底色"心智

**实现细节**：
| | 左（日文） | 右（中文） |
|---|---|---|
| 底色 | 白 | 灰 `#E4E4E4` |
| 文字 | 黑 | 黑 |
| 译文 | 黑 50% | 黑 50% |
| 圆角 | 左上角收窄 4pt | 右上角收窄 4pt |
| 描边 | 发丝线（黑 6%） | 无 |
| 阴影 | 极淡投影 | 扁平 |

- `bubbleGray` 从 `#F2F2F2` 调深到 `#E4E4E4`（原来太接近 `#F5F5F5` 背景看不出来）
- 不对称圆角用 `UnevenRoundedRectangle`（iOS 16.4+），形成"指向感"
- 白气泡加发丝描边，在浅灰背景上保持轮廓清晰

### 3. 其他优化

- **发送按钮**：左右两个 `arrow.up.circle.fill` 统一改为纯黑（`.black`）
- **LoadingOverlay 轻量化**：去掉全屏 `Color.black.opacity(0.3)` 遮罩（导致发送时闪黑），改为居中白色小卡片 + 转圈 + "正在翻译..."

## 关键设计决策

1. **放弃微信风格光标选取**：SwiftUI Text 无法程序化触发光标，UIKit UITextView 方案不稳定。用户选择回归小红书风格（一键复制），更干净
2. **左白右灰而非左白右黑**：灰阶比纯黑更安静，符合日系极简定位
3. **不对称圆角**：借鉴 iMessage/Telegram，气泡靠边缘的上角收窄成 4pt，增加手工质感

---

## 踩坑记录（本次新增）

1. **contextMenu 预览动画无法优雅去除**：`preview:` 参数传 EmptyView 变白点、传自定义视图会缩小+白框。唯一干净方案是完全不用 contextMenu，改用 onLongPressGesture + 自定义 overlay
2. **textSelection 会拦截长按手势**：`.textSelection(.enabled)` 会让系统弹出"拷贝/分享"菜单，覆盖自定义 onLongPressGesture。要自定义长按必须移除 textSelection
3. **Capsule 菜单文字截断**：HStack 里的 Text 会被压缩成"..."，需 `.fixedSize()`
4. **全屏加载遮罩会闪黑**：翻译太快（<0.5s），全屏黑色遮罩一闪而过体验差，改为轻量非阻塞卡片
